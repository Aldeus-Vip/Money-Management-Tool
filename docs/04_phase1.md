# Phase 1 実装内容

## 1. 画面

| 画面 | できること |
|---|---|
| 接続 | 既存の .sqlite を開く / 新規作成 / 前回のファイルを再開 / ブラウザ内保存 (暫定) |
| PIN | 初回設定 (4〜8桁) / ロック解除。10分無操作で自動ロック |
| ダッシュボード | 自由枠の残り (リング), 予算4枠の消化と理想ペース, 警告, 日別支出, 固定費の引落予定, ウォレット別支出, 最近の取引 |
| 取引入力 | ウォレット・区分・金額 (「1009+1133」の足し算可)・用途 (新しい用途は自動登録)・日付・メモ |
| 取引一覧 | 期間/全期間, ウォレット・区分・文字で絞込, 日別グループ, タップで編集・削除 |
| 月次予算 | 給料を登録して期間を開始, 配分の入力, 計算の流れ (Excel の目的設定), 期間ごとの固定費の金額調整 |
| マスタ管理 | 用途 (既定の区分・課金フラグ・ウォレット限定) / 固定費 / ウォレット名 |
| 設定 | 保存状態, バックアップのダウンロード, 外部変更の解決, 給料日ルール, 計算係数, PIN 変更 |

Phase 2 の画面 (口座・残高 / 固定費 / 貯蓄・プール / 分析) はメニューに「P2」と表示。

## 2. 計算 (Excel との対応)

| 項目 | 式 | Excel |
|---|---|---|
| 固定費支払後 | 給料 + 賞与(ON) − 固定費 | 目的設定!D24 |
| 自由枠 | 固定費支払後 − 食費予算 | D28 |
| 自由枠 合計 | 自由枠 + 受取金 + その他加算(暫定) | K7 ※繰越は保留 |
| 臨時費用 枠 | 自由枠合計 − 課金上限 − 娯楽上限 − 貯金移動 − 娯楽費移動 | K20 |
| 臨時費用 使用 | 交通費 + 臨時費用 + その他 | K26 ※手数料は Phase 2 |
| 自由枠 残り | 自由枠合計 − 課金 − 娯楽費その他 − 臨時費用使用 − 移動額 | K28 |
| 食費 推奨 | 過去12期間の食費平均 × 1.05 | E26 |
| 臨時費用 推奨最低額 | 過去平均 × 1.05 + 最低額 | L20 |
| 固定費 推定 | 過去の実額 (0除く) 平均 × (1 + 10%※バッファ対象) | 銀行口座!L列 |
| 給料日 | 25日。土日・祝日は前の営業日 | 使用状況!E2 (祝日は追加) |

## 3. データの保存

- ブラウザ内で SQLite (sql.js) を動かし、変更から 0.5 秒後にファイルへ自動保存
- 保存前にファイルの更新時刻を確認し、外部 (別端末) で変わっていれば上書きせず警告
- PIN は画面ロック。ファイル自体は暗号化しない

## 4. 動作環境

| 環境 | 状況 |
|---|---|
| PC Chrome / Edge | ファイル直接保存 (OneDrive 同期フォルダ可) |
| スマホ | 画面は対応済み。保存は「ブラウザ内保存」のみ (OneDrive 連携は Phase 3) |
