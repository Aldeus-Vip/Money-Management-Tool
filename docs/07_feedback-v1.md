# フィードバック対応 (v1 → v2)

## 1. 不具合

| 内容 | 対応 |
|---|---|
| 表の中の金額入力で ¥ と数字が重なる | 表のスタイルが入力欄の左余白を上書きしていた → 修正 |
| 「娯楽費その他」が 0 円でもエラー | エラーは「残りがマイナス (0 未満)」のときだけ。ちょうど 0 は「使い切り」 |

## 2. 固定費 (Excel の運用を再現)

| Excel | アプリ |
|---|---|
| 固定費List (L 列) の数値 = 固定 | マスタの算出方法「固定額」 |
| 固定費List (L 列) の数式 = 平均 × バッファ | マスタの算出方法「過去平均」(直近 12 期間の手入力した引落額の平均) + バッファ |
| 目的設定 D 列 (予算) | 期間ごとの「予算額」→ 月次予算・自由枠の計算 |
| 銀行口座の支払予定表 F 列 (引落) | 期間ごとの「引落額」→ 口座残高 (✓ で引落済) |
| 関数 = マスタから自動 / 数値直打ち = 手入力 | 未入力 = 「自動」(シアンの点線枠) / 入力 = 「手入力」(アンバーの枠) |
| 関数を入れ直してマスタ参照に戻す | ↺ ボタン (マスタに戻す) |
| 条件付き書式で塗り分け | 「自動」「手入力」バッジと枠の色 |

- 自動の金額はマスタを変更すると追従する (手入力は変わらない)
- マスタ管理画面で「今の自動額」を確認できる

## 3. 入力・照合画面 (新)

残高を実際の金額と照合しながら 1 件ずつ入力する運用に合わせて、1 画面にまとめた。

| 場所 | 内容 |
|---|---|
| 上 | ウォレットごとに「現在 (計算)」「実際の金額 (入力)」「差」。一致で ✓。直前の増減を表示 |
| 左 | 入力 (支出・受取 / 移動)。式 (+ − × ÷ 括弧)、弁当代の計算 (単価 × 日数) |
| 右 | 選んだウォレットの通帳形式の明細 (1 行ごとに残高)。行をタップで編集。登録した行は光る |

- デビットは普通口座の明細に含めて表示
- 口座・残高画面の列順を「現在 → 実際 → 差 → 期首 → 増減」に変更

## 4. その他の追加

- 金額の式: `400*5`, `(1200+800)×2`, `3000÷3` など
- 弁当の単価 (設定画面、既定 400 円)
- 取引一覧に「用途別集計」(回数・合計)

## 5. スキーマ v3

`fixed_costs.mode` (fixed / average)、`period_fixed_costs.planned` / `actual` (NULL = 自動) を追加。
v2 の DB は開いたときに自動で更新され、入力済みの金額は「手入力」として保持される。
