## 2. 残高の計算

| ウォレット | 式 |
|---|---|
| 普通口座 (現在) | 期首 + 給料 + 賞与(ON) − 引落済の固定費 − 貯金・娯楽費への移動 + プールからの使用 ± 移動 − 支出 (口座・デビット) + 受取金 |
| 普通口座 (見込み) | 現在 − 未引落の固定費 |
| 現金 / PayPay / Suica | 期首 ± 移動 − 支出 + 受取金 |
| 不明金 | 計算残高 − 実残高 (+ = 使途不明 / − = 記録漏れの収入) |

- デビットの支出は普通口座から引く
- Excel の「振込」(外部からの入金) = 普通口座の「受取金」
- 移動の手数料 = 「その他 / 手数料」の支出 → 臨時費用の使用額に含む (Excel K26 と同じ)
- プールからの使用 = 口座に戻り、その期間の自由枠に加算 (Excel K4 と同じ)

## 3. 繰越 (相談中)

- 期首残高は「前期間の残高を引き継ぐ」ボタンで設定 (実残高があればそれ、なければ計算残高)
- 自由枠への加算は 2 方式を用意
  - OFF (既定): 月次予算の「その他加算」に手入力
  - ON (Excel 方式): 期首残高の合計を自由枠に加算

## 4. 実食費 vs 計算食費 (Excel S7/T7) について

アプリでは残高をすべて取引から計算するため、この 2 つは常に一致する (Excel では手入力値のずれを検出していた)。
代わりに **ウォレットごとの不明金** (実残高との差) で同じ目的を果たす。
