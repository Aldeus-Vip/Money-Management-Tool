# 固定費の請求月と金額の予定

年 1 回の支払いや、特定の月からの料金変更を、マスタに先に登録しておく仕組み。
(Excel では費用実績の先の月に金額を入れておき、月替わりに意識していた)

## 1. 登録 (マスタ管理 → 固定費)

| 項目 | 内容 | 例 |
|---|---|---|
| 請求月 | 毎月 / 偶数月 / 奇数月 / 年 1 回 (○月) / 指定 (1〜12 月から選択) | 水道代 = 偶数月、年会費 = 11 月 |
| 予定: 以降ずっと | その年月から金額が変わる (値上げ・値下げ) | 家賃 2026/09〜 |
| 予定: 毎年この月 | 毎年決まった月の金額 (年払い) | ○○ 毎年 5 月 |
| 予定: その月だけ | 一時的な金額 | 2027/06 のみ |

- 年月 = 給料日が属する月 (期間)
- 自動額の優先順位: その月だけ → 毎年この月 → 以降ずっと → マスタの金額 (固定額 / 過去平均)
- 「毎年この月」「その月だけ」がある月は、請求月以外でも自動で入る

## 2. 反映されるところ

| 画面 | 表示 |
|---|---|
| 月次予算 (給料を登録する前) | 「開始すると入る固定費のお知らせ」。予算の仮計算も請求のある固定費だけで行う |
| 期間の開始 | 請求月の固定費だけが自動で入る (自動額は予定の金額) |
| ダッシュボード | 「今期の固定費のお知らせ」「来期の予定」 |
| 固定費 | お知らせ + 各行に請求月・予定の根拠 |
| 分析 (費用実績) | これからの月を「予」として薄く表示 (閲覧のみ・平均に含めない) |

## 3. お知らせの種類

| 記号 | 内容 |
|---|---|
| ▲ | この期間から金額変更 (前 → 後) |
| ◆ | この期間だけの金額 |
| ● | 年 1 回・隔月などの請求がある |
| — | 請求なし (前の期間に請求があった場合のみ表示) |

## 4. スキーマ v4

`fixed_costs.bill_months` (NULL = 毎月) と `fixed_cost_rules` を追加。既存の DB は開いたときに自動で更新される (既存の金額は変わらない)。
